# How to run
From the project root:

Run the program 

```bash
python main.py
```

This loads the course catalog from course_catalog.csv and student data from university_data.csv then populates the university.

Run the tests

From the project root:

```bash
python test.py
```

The tests use unittest and cover the Course, Student, and University classes in main.py.
